# Launch: personal only

Not shipping to itch/Steam/App Store.

## How you run it

1. `godot --path game`
2. Or export macOS via Project → Export → macOS preset → `build/PipeHop.app` (install export templates first)

## Do not

- Use Nintendo names, art, or audio
- List as a Mario clone in public stores
- Skip the brand sweep if you later share builds with others
